# Placement links

Each folder here is one short link for a book placement. The page sends the visitor to the Drink Soberishly page on Amazon:

https://www.amazon.com/dp/B0HQFQPNTW

GitHub Pages serves `go/<slug>/index.html` at `https://drinksoberishly.com/go/<slug>/`. The same path without a trailing slash redirects to that address, then the page continues on to Amazon. Either form works.

These pages use `noindex`. This repo has no sitemap. If you add one later, leave `/go/` out of it.

## Add a slug

1. Copy a folder, for example `go/clubsoda`, to `go/<newslug>`.
2. Keep the new slug lowercase.
3. Leave `index.html` as it is. Every placement uses the same Amazon address.
4. Add the new slug to the list above.
